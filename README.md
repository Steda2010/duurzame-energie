# Duurzame Energie

Een kleine Flask-webapp over duurzame energie.

## Run locally

```bash
python app.py
```

Open http://127.0.0.1:5000

## Collaborate on GitHub

1. Create a GitHub repository.
2. Push the project with:

```bash
git remote add origin https://github.com/<your-username>/<your-repo>.git
git branch -M main
git push -u origin main
```

3. Invite your friend as a collaborator on GitHub.
4. Both of you can clone, branch, commit, and open pull requests.
